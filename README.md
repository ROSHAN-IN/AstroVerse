# AstroVerse 🚀

**Explore Beyond Imagination.**

AstroVerse is an interactive space exploration website being developed
by a team of four college students.

The project combines educational space content with animated 3D
experiences using HTML, CSS, JavaScript, Three.js, and GSAP.

## Project Status

Initial setup is in progress.

The shared repository has been created, all four members have cloned
it, and the three feature developers have created their assigned
branches and starter files.

The features listed below are planned and are not yet complete.

## Planned Features

### Solar System

- Animated Sun and all eight planets.
- Planetary orbits and rotation.
- Interactive planet selection.
- Animated space background.

Planet sizes, distances, and orbital speeds will be adjusted for
clear viewing rather than displayed to scale.

### Planet Explorer

- Interactive 3D planet models.
- Planet facts and information.
- Zoom and rotation controls.

### Space Missions and Quiz

- Information about space missions.
- An educational quiz with at least 10 questions.
- XP points and achievements.
- A leaderboard, with its storage approach to be decided.

### Homepage

- AstroVerse branding and navigation.
- Animated space hero section.
- Links to all three feature pages.
- About section and footer.

## Technology Stack

- HTML5 for page structure.
- CSS3 for styling and responsive layouts.
- JavaScript for interactions and quiz logic.
- Three.js for 3D graphics.
- GSAP for interface animations.
- Git and GitHub for version control and collaboration.

## Collaboration Rules

1. Use the same shared repository.
2. Each developer works on their assigned feature branch.
3. Edit only assigned files unless the team agrees otherwise.
4. Each member stages, commits, and pushes their own work.
5. Feature developers open Pull Requests targeting main.
6. Roshan reviews and merges approved Pull Requests.
7. Feature developers must not push feature work directly to main.
8. Check git status before staging or committing.
9. Keep filenames and folder capitalization consistent.
10. Report merge conflicts before attempting unfamiliar fixes.
